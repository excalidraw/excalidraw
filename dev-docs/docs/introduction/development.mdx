## Local Installation

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Requirements

- [Node.js](https://nodejs.org/en/)
- [Yarn](https://yarnpkg.com/getting-started/install) (v1 or v2.4.2+)
- [Git](https://git-scm.com/downloads)

### Verify the installation

Before proceeding, verify that the required tools are installed by running the following commands in your terminal:

```bash
node --version
yarn --version
git --version
```

If any command is not recognized, install the corresponding tool using the official installation guide linked above. Make sure your Node.js version is compatible with the requirements of the current repository.

### Clone the repo

```bash
git clone https://github.com/excalidraw/excalidraw.git
```

### Install the dependencies

Navigate to the cloned repository and install the dependencies:

```bash
cd excalidraw
yarn
```

### Start the server

Start the development server:

```bash
yarn start
```

Once the server is running, open [http://localhost:3000](http://localhost:3000) in your browser and start coding in your favorite code editor.

### Troubleshooting

**The `yarn` command is not recognized**

Verify that Yarn is installed and available in your terminal. If necessary, follow the official [Yarn installation guide](https://yarnpkg.com/getting-started/install).

**The development server does not start**

1. Check the terminal output for error messages.
2. Confirm that the dependencies were installed successfully.
3. Verify that your Node.js version meets the repository's requirements.
4. If the port is already in use, identify the process using it or use the local URL reported by the development server.

**The application does not open at `http://localhost:3000`**

Confirm that the development server is still running. Check the terminal output for the correct local URL and any startup errors.

## Commands

### Reformat all files with Prettier

```bash
yarn fix
```

### Run tests

```bash
yarn test
```

### Update test snapshots

```bash
yarn test:update
```

### Test for formatting with Prettier

```bash
yarn test:code
```

### Docker Compose

You can use Docker Compose to work on Excalidraw locally if you prefer not to set up a Node.js environment.

```bash
docker-compose up --build -d
```

## Self-hosting

We publish a Docker image with the Excalidraw client at [excalidraw/excalidraw on Docker Hub](https://hub.docker.com/r/excalidraw/excalidraw). You can use it to self-host your own client under your own domain, on Kubernetes, AWS ECS, etc.

```bash
docker build -t excalidraw/excalidraw .
docker run --rm -dit --name excalidraw -p 5000:80 excalidraw/excalidraw:latest
```

The Docker image is free of analytics and other tracking libraries.

**At the moment, self-hosting your own instance doesn't support sharing or collaboration features.**

We are working towards providing a full-fledged solution for self-hosting your own Excalidraw.
