# Development

## Local Installation

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Requirements

- [Node.js](https://nodejs.org/en/)
- [Yarn](https://yarnpkg.com/getting-started/install) (v1 or v2.4.2+)
- [Git](https://git-scm.com/downloads)

### Clone the repo

```bash
git clone https://github.com/excalidraw/excalidraw.git
```

### Install the dependencies

```bash
yarn
```

### Start the server

```bash
yarn start
```

Now you can open [http://localhost:3000](http://localhost:3000) and start coding in your favorite code editor.

```bash

```

### Run tests


### Update test snapshots

```bash

```

### Test for formatting with Prettier

```bash

```

### Docker Compose

You can use docker-compose to work on Excalidraw locally if you don't want to setup a Node.js env.

```bash
docker-compose up --build -d
```

## Self-hosting

We publish a Docker image with the Excalidraw client at [excalidraw/excalidraw](https://hub.docker.com/r/excalidraw/excalidraw). You can use it to self-host your own client under your own domain, on Kubernetes, AWS ECS, etc.

```bash
docker build -t excalidraw/excalidraw .
docker run --rm -dit --name excalidraw -p 5000:8080 excalidraw/excalidraw:latest
```

The container serves the app on port `8080` (not `80`) and runs nginx as an unprivileged user, so it can be run in a hardened mode with any UID, a read-only root filesystem and no Linux capabilities. Only `/tmp` needs to be writable:

```bash
docker run --rm -dit --name excalidraw -p 5000:8080 \
  --user 1010:1010 \
  --read-only --tmpfs /tmp \
  --cap-drop=ALL --security-opt no-new-privileges \
  excalidraw/excalidraw:latest
```

On Kubernetes, mount an `emptyDir` volume at `/tmp` and set `readOnlyRootFilesystem: true`, `runAsNonRoot: true`, `allowPrivilegeEscalation: false` and `capabilities: { drop: ["ALL"] }` in the container's `securityContext`.

:::note
Before this change the image listened on port `80`. Update existing port mappings from `-p <host>:80` to `-p <host>:8080`. The container listens on IPv4 only.
:::

The Docker image is free of analytics and other tracking libraries.

**At the moment, self-hosting your own instance doesn't support sharing or collaboration features.**

We are working towards providing a full-fledged solution for self-hosting your own Excalidraw.
